## Findings
1. **Hauling drops a lot.** Prime-50 coalition truck deliveries fall 54–72% (64.5 → 18–30 per hour), and Static deliveries fall 18–28%. Resupply postings barely move (9.1 → 7.6–8.3 per hour), so the cut is in how much each run carries and how often a base asks again, not in how many bases ask.
2. **Everything else gets worse at prime-50, in every variant.**
   - Starved node-minutes against the new, lower floor rise 1.7–3×.
   - Newbie first impact slows (A2 median 147 s → 305–402 s; tail 33.6% → 41–44%). Every kind is slower, the strikers most (118.8 s → 275–426 s).
   - The Static launches 15–27% fewer Offensives.
   - Momentum falls about 10–13 points.
   - The cause of the slower first impact is [UNVERIFIED]. The likely path is a thinner forward stock: rearm and forward deploys draw on bases now kept near 200–400 instead of 800–1600.
3. **Overnight-0 goes back to the pre-NX-473 static war.**
   - Coalition deliveries are 0 and coalition income is 0.0, because the rear pool sits at its 6000 cap.
   - Momentum is 41.0 in all three variants, exactly X0's value before LC-1.
   - With targets this low, no base asks for stock, so no trucks run, the pool never drains, and income clips to 0.
4. **Higher M is better on most lines but never reaches the control.** At M20: starved 328 vs 198, A2 tail 40.7% vs 33.6%, Offensives 182 vs 215, deliveries 29.7 vs 64.5.
5. **The probe does not test the owner's actual goal.** That goal is that hauling should not *grow* when storage grows. All four runs used today's storage, so they show the absolute effect of lower targets, not storage-independence.
