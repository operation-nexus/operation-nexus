## Visualizer kernel audit (2026-10-26)

| ID | Question | Recommendation (lead) | Priority | Status |
|---|---|---|---|---|
| Q-VIZ-1 | Terrain masking from a heightmap (audit V-3, V-4): keep Q-FOW-3's per-area masking or move to line of sight? | **Keep per-area masking. Derive the masking cells offline from the Q-CFG-3 PNG heightmap** (an integer table in the config hash: deterministic and cheap). The alternative, live line of sight, reopens Q-FOW-3: it needs a height per band and sensor and many height samples per sensor-target pair every `fow.track_every_ticks` (5) ticks (cost unmeasured), and is size L by the lead's estimate. Timing: after P1 balance. The visualizer's raw `.bin` and its runtime sin/cos fallback are both out (Q-CFG-3, DATA-INTEGRITY) | P2 | ✅ 2026-10-26 (owner, #383): the recommendation |
| Q-VIZ-2 | Curved roads (audit V-6) | **Optional polyline points on each theater edge.** Length becomes the polyline length, ground units follow the points, and the bridge cut point is projected onto the line (size M; goldens and travel times move). Not new junction or abutment nodes: nodes are capturable, hold stock and drive the director. Not renderer-only curves either, which would draw trucks off the road. Defer until a reference terrain exists | P2 | ✅ 2026-10-26 (owner, #383): the recommendation |
| Q-VIZ-3 | Altitude and fuel for the renderer (audit V-11, V-13) | **Altitude: the renderer maps the unit catalog's `default_alt_band` to a display height** (the band is fixed per kind, so no wire change). **Fuel: add an own-side-only `fuel_pct` to `EntityView` when a HUD needs it** (CONTRACTS §7, size S). No height, vertical speed or attitude enters the kernel | P2 | ✅ 2026-10-26 (owner, #383): the recommendation |
| Q-VIZ-4 | NOE canyon runs (audit V-2) | **Keep Q-CBT-11: no command changes band in the first build; band changes stay in GAMEPLAY-LATER.** The renderer must not show a canyon run for a unit the sim has at MED (DI-1). The alternative reopens Q-CBT-11 with a new command (schema, parser and handler together, rule 6a) and content that allows NOE (size M) | P3 | ✅ 2026-10-26 (owner, #383): the recommendation |
| Q-VIZ-5 | A view of the AI's decisions (audit V-18) | **After a campaign ends, show only real director state:** CP, tier, provocation, and the chosen operation with the advisor's `rationale`. The director is rule-based and has no probabilities to show; inventing them breaks rule 0. The alternative is a decision-trace event added to the spec | P3 | ✅ 2026-10-26 (owner, #383): the recommendation |
